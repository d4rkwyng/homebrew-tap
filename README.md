# d4rkwyng's Homebrew tap

Homebrew asks you to trust a third-party tap once before it loads its casks:

```sh
brew trust --tap d4rkwyng/tap
```

Then:

```sh
brew install --cask d4rkwyng/tap/johnny-castaway        # the app + screensaver
brew install --cask d4rkwyng/tap/johnny-castaway-saver  # the screensaver only
brew install --cask d4rkwyng/tap/first-light           # the living Apple-1
brew install --cask d4rkwyng/tap/tankard               # Tankard, a native app for Homebrew
brew install --cask d4rkwyng/tap/owlink                # Owlink, a fast, simple text editor
brew install --cask d4rkwyng/tap/parallels@26          # Parallels Desktop 26, pinned for Intel Macs
```
